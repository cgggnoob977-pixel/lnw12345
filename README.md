# ห้องสมุด Insight — ระบบวิเคราะห์การยืม-คืน

เว็บไซต์แดชบอร์ดภาษาไทยสำหรับสำรวจชุดข้อมูล `library_book_loans_dirty_150.csv` ตามโจทย์ฝึกวิเคราะห์ข้อมูลห้องสมุด

## เปิดใช้งานบน Windows

1. ติดตั้ง Python 3 หากเครื่องยังไม่มี (ใช้เฉพาะเว็บเซิร์ฟเวอร์และสคริปต์เตรียมข้อมูล ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
2. ดับเบิลคลิก `launch.bat` ในโฟลเดอร์นี้
3. เว็บจะเปิดที่ <http://127.0.0.1:8000> หากไม่เปิดอัตโนมัติ ให้เข้า URL นี้เอง
4. กรอกชื่อใดก็ได้และรหัสผ่าน `12345`
5. ปิดหน้าต่าง Command Prompt เพื่อหยุดเว็บเซิร์ฟเวอร์

ต้องเก็บโฟลเดอร์ `assets` ไว้ข้าง `index.html` และไม่ควรเปิด `index.html` ด้วยการดับเบิลคลิก เนื่องจากเบราว์เซอร์จะไม่อนุญาตให้หน้าเว็บอ่าน CSV ผ่าน `file://`

## หน้าจอและการใช้งาน

- **ภาพรวม** — KPI 5 ค่า, ยอดยืมตามหมวด, หนังสือยอดนิยม 5 อันดับ, แนวโน้มรายเดือน, สถานะการคืน, สถิติและการกระจายจำนวนวัน
- **รายการยืมทั้งหมด** — ค้นด้วยรหัสยืม รหัสผู้ยืม หรือชื่อหนังสือ; คลิกหัวคอลัมน์เพื่อเรียง; ส่งออก CSV ตามตัวกรองและคำค้น
- **ติดตามค้างคืน** — ตารางรายการที่ยังไม่คืนและเกินกำหนด ณ วันอ้างอิง; ส่งออก CSV ได้
- **คุณภาพข้อมูล** — ประเด็นผิดปกติพร้อมแนวทางจัดการ ส่งออกรายการปัญหาได้
- **ข้อค้นพบ** — สรุปประเด็นและข้อเสนอแนะจากข้อมูลที่เลือก
- **พจนานุกรมข้อมูล** — คำอธิบายทั้ง 9 ฟิลด์และนิยามตัวชี้วัด

ไฟล์ `assets/data_dictionary.csv` เป็น Data Dictionary สำหรับส่งมอบ และหน้าพจนานุกรมในเว็บมีข้อมูลเดียวกัน

แถบตัวกรองวันที่ยืม หมวดหมู่ กลุ่มสถานะ และคำค้นจะแสดงบนหน้าภาพรวม รายการยืม ติดตามค้างคืน และข้อค้นพบ กด **ล้างตัวกรอง** เพื่อล้างเงื่อนไขทั้งหมด เมนูด้านซ้ายจะเปลี่ยนเนื้อหาเป็นหน้าที่เลือก ไม่ได้ต่อเนื้อหาเป็นหน้าเลื่อนยาว

## การเตรียมและตรวจสอบข้อมูล

- เก็บ CSV ต้นฉบับไว้ใน `assets/library_book_loans_dirty_150.csv`; เว็บไม่เขียนทับหรือแก้ไขไฟล์ต้นฉบับ
- ตัดรหัสการยืมที่ซ้ำออกจากการวิเคราะห์ โดยเก็บรายการแรกไว้ และยังแสดงแถวซ้ำในหน้าคุณภาพข้อมูล
- ตัดช่องว่างหัวท้ายก่อนจัดกลุ่มหมวดหมู่; ไม่เติมวันที่คืนหรือค่าที่ไม่มีหลักฐาน
- เก็บรายการผิดปกติให้ตรวจสอบได้ และแยกออกเฉพาะตัวชี้วัดที่คำนวณไม่ได้
- เรียก `py prepare_data.py` เพื่อสร้าง `assets/library_book_loans_prepared_149.csv` ซ้ำได้; ใช้ Python standard library เท่านั้น
- ไฟล์พร้อมใช้ตัดเฉพาะแถวรหัสการยืมซ้ำ เก็บรายการผิดปกติอื่นไว้ และตัดช่องว่างหัวท้ายโดยไม่เดาค่าว่างหรือแก้วันที่ที่ผิด
- วันอ้างอิงเป็น **15 พฤศจิกายน 2026** อย่างคงที่ ไม่ใช้วันที่ปัจจุบันของเครื่อง
- สถานะคืนแล้ว/ยังไม่คืนที่ขัดแย้งกัน และกำหนดคืนก่อนวันยืม จะถูกจัดเป็น “ประเมินไม่ได้”
- ระยะเวลายืมและวันล่าช้าคำนวณเป็นผลต่างวันปฏิทิน ไม่บวกหนึ่งวัน; วันกำหนดคืนถือว่าคืนตรงเวลา
- KPI กราฟ และตารางในหน้าภาพรวมใช้ชุดข้อมูลหลังตัดรายการซ้ำและตัวกรองเดียวกัน; ตัวหารของแต่ละตัวชี้วัดใช้เฉพาะรายการที่ประเมินได้

## ข้อจำกัดของข้อมูล

ชุดข้อมูลไม่มีจำนวนหนังสือคงคลังและประวัติการต่ออายุ จึงไม่ควรสรุปจำนวนเล่มที่ควรจัดซื้อหรือสรุปสาเหตุการคืนช้าจากข้อมูลชุดนี้เพียงอย่างเดียว หน้าเข้าสู่ระบบเป็นเพียงประตูสำหรับสาธิตบนเว็บสแตติก ไม่ใช่ระบบยืนยันตัวตนที่ปลอดภัยสำหรับเผยแพร่ข้อมูลจริง

## ตรวจการทำงานแบบย่อ

1. เข้าระบบด้วยชื่อทดสอบและรหัสผ่าน `12345`; รหัสผิดต้องแสดงข้อความผิดพลาด
2. ตรวจว่าหน้าภาพรวมโหลดข้อมูลและแสดงตัวเลขหลังตัดข้อมูลซ้ำ
3. เลือกหมวดหมู่หรือช่วงวัน แล้วตรวจว่าตัวเลขและกราฟเปลี่ยนตาม
4. ค้นหารหัสยืมหรือชื่อหนังสือ แล้วตรวจผลตารางและไฟล์ CSV ที่ส่งออก
5. ตรวจรายการค้างคืนโดยเทียบกับวันอ้างอิง 15 พ.ย. 2026 และเปิดหน้าคุณภาพข้อมูลเพื่อตรวจประเด็นผิดปกติ
